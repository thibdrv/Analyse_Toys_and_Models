Here are the files included in this folder :

- Data_Cleaning_with_Pandas.ipynb (outputs Toys_and_Models_Cleaned.csv for analysis)

Description  : A Jupyter notebook focused on data cleaning using Python.
What it does : Preprocesses raw data to make it ready for analysis (handling missing values, removing duplicates, formatting columns, etc.).

- EDA_in_Pandas.ipynb

Description  : A Jupyter notebook dedicated to Exploratory Data Analysis (EDA).
What it does : Explores the dataset using descriptive statistics and data visualizations to identify key trends, anomalies, and distributions.

- Supply_Chain.ipynb (KPI Toys and Models)

Description  : A Jupyter notebook focused on supply chain analytics.
What it does : Performs analysis and modeling on inventory management, logistics, order fulfillment, and delivery lead times.
